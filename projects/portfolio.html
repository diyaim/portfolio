Contexte

Ce projet consiste à partir d’un site de portfolio existant afin de le corriger, l’optimiser puis le personnaliser pour en faire un portfolio professionnel destiné aux recruteurs.

Le portfolio doit à la fois présenter mon profil, mes compétences et mes projets, tout en démontrant mes capacités techniques à travers le code et l’interface du site.

Objectifs

  • Corriger les bugs existants dans le code du site.
  • Améliorer les performances et l’accessibilité du portfolio.
  • Respecter les bonnes pratiques SEO et d’accessibilité.
  • Personnaliser le contenu pour refléter mon profil et mes compétences.
  • Mettre le site en ligne et le rendre accessible publiquement.

Réalisation

  • Correction des bugs d’affichage (icônes Font Awesome, éléments dynamiques).
  • Optimisation des images, contrastes et niveaux de titres.
  • Analyse des performances avec Lighthouse et WAVE WebAIM.
  • Personnalisation des sections : profil, compétences et projets.
  • Ajout d’au moins deux projets avec description et liens vers GitHub.
  • Déploiement du portfolio en ligne (GitHub Pages).
